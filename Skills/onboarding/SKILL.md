# Configurar a instalação

Antes de operar, cumpra a [regra de onboarding humano obrigatório](../../AGENTS.md#o-formulário-html-é-obrigatório-e-pertence-ao-humano). Rode `cd vagas && npm run onboarding`; sem registro humano, aguarde a pessoa concluir o HTML. Não preencha nem contorne por ela.

Leia as [instruções da instalação](../../AGENTS.md) e siga o [onboarding](../../ONBOARDING.md). Confira os blocos já preenchidos e retome o que falta, sem repetir perguntas resolvidas nem substituir dados por exemplos.

O onboarding prepara perfil, currículo, fontes e conexões; esta entrada não inicia candidaturas. Preserve o opt-in e confirme as autorizações exigidas pelos procedimentos. Crie uma agenda somente quando o prompt de instalação ou uma escolha explícita já a autorizar, seguindo [ATUALIZAR.md](../../ATUALIZAR.md) para a checagem de releases e o runbook próprio para autonomia de operação. Não afirme que uma tarefa foi criada sem confirmação da ferramenta.
