# JobRelay 1.5.1: currículos com nota de ATS mais alta

Versão 1.5.1  
11 de novembro de 2026  
Para atualizar, confirme quando o assistente avisar. Seus dados continuam onde estão.

## ✨ Melhorias

- **Nota de ATS em todo currículo:** cada currículo adaptado agora só sai com pelo menos 80% das palavras-chave da vaga, a faixa que os sistemas de triagem favorecem.
- **Adaptação mais certeira:** o assistente usa as palavras exatas do anúncio para o que você já fez, sem inventar experiência, e pergunta quando tiver dúvida.
- **Revisão do currículo:** o revisor confere a qualidade de cada currículo antes do envio e devolve para refazer quando não está bom.
